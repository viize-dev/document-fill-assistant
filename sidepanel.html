ตั้งค่าการอ่านเอกสาร (OCR)
วิธีเชื่อมต่อ AI

เข้าสู่ระบบด้วยบัญชีองค์กร (Google Workspace / Microsoft 365) หน่วยงานเป็นผู้ดูแล key และค่าใช้จ่ายของ AI เอกสารจะถูกส่งผ่านระบบขององค์กรไปยังผู้ให้บริการ AI ที่หน่วยงานเลือก

ยังไม่รองรับการ login ด้วยบัญชีส่วนตัวของ ChatGPT / Claude / Gemini เพราะแพ็กเกจรายเดือนของแอปเหล่านั้นไม่เปิดให้แอปอื่นใช้ (Claude ห้ามโดยเงื่อนไข) หากไม่มีระบบขององค์กร ให้เลือก "ใช้ API key ของตัวเอง"

ยังไม่มี API key? ดูวิธีขอ
    เปิดหน้าสมัคร/สร้างคีย์

    API key คือรหัสที่ใช้เรียก AI คิดค่าใช้จ่ายตามการใช้งานจริง แยกจากแพ็กเกจรายเดือนของแอปแชต

    ไม่ใช้ AI อ่านข้อความที่อยู่ในไฟล์ PDF แล้วแยกฟิลด์ด้วยกฎ ข้อมูลไม่ออกจากเครื่อง ไม่ต้องมี key และไม่มีค่าใช้จ่าย

    • PDF ที่มีข้อความในไฟล์ (เช่น ส่งออกจากระบบสารบรรณ/Word) อ่านได้แม่นที่สุด ส่วน ภาพสแกน อ่านด้วย OCR ในเครื่อง (ช้ากว่า ~5–10 วินาที ใช้หน้าแรกเท่านั้น) เลขที่หนังสือ วันที่ ตราประทับ ลายมือ มักผิด ต้องตรวจเสมอ
    • แม่นยำกับหนังสือราชการรูปแบบมาตรฐาน แต่ผิดได้เมื่อรูปแบบต่างไป ระบบจะไฮไลต์ช่องที่ไม่แน่ใจ ผู้ใช้ต้องตรวจก่อนกรอก
    • สรุปเรื่องสำหรับใบปะหน้าทำไม่ได้ (ใช้ข้อความต้นฉบับท่อนแรกแทน)

    key เก็บในเครื่องนี้เท่านั้น (chrome.storage.local) เอกสารที่วิเคราะห์จะถูกส่งไปยังผู้ให้บริการที่เลือก ตรวจนโยบายข้อมูลของหน่วยงานก่อนใช้กับเอกสารจริง
